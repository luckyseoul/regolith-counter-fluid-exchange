# Simulations

All particle-scale work is in `custom_gpu_dem/`: a single-GPU DEM (CuPy) with a physical lid, cell-list contacts, and real gas drag with local porosity.

Rung 1 (coarse fraction + iron) is the high-N physical-lid campaign plus the good-variable real-drag operating point. See [DATA.md](../DATA.md).

Standalone engine extract: [luckyseoul/custom-gpu-dem](https://github.com/luckyseoul/custom-gpu-dem).
